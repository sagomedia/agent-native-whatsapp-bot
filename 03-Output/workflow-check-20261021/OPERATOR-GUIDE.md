# ShopBot: one short demonstration, then practice

Use the **? Quick help** button whenever you need these steps. Help opens in English or Tamil and never performs a shop action by itself. Start on **Today** to see what needs attention.

This is a teaching aid, not evidence that a novice has already passed the tasks. The intended shop staff still need to try the practice exercise below.

## The four daily jobs

| Job | What to do | What success means |
|---|---|---|
| Send a quote | Orders → Needs review → select the right customer/order. Check the item/photo, quantity, selling unit and actual shop price. Resolve items focuses the next missing or invalid fact. Use a store item if it is absent from the digital catalog. Send quote for approval. | The quote is saved for customer approval. Check whether WhatsApp was queued or needs attention. **Save draft** keeps your work without sending. |
| Prepare a pickup | After customer approval, check the shelf and any required advance, then Accept order. Pack the approved quantities/variants, then Mark ready for pickup. Hand over the goods, then Mark collected. | Acceptance holds stock; collection deducts it. Collection does **not** record payment. |
| Update a price or stock | Products → Update price → enter the price per selling unit → Save price. For stock, choose Receive stock, Record walk-in sale or Correct count. Unknown stock starts with a physical count. Check the resulting quantities before saving. | On shelf includes items held for orders. Available = on shelf minus held. A price update leaves stock unchanged. |
| Reply to a customer | Messages → select the customer → Take over & reply → write → Send reply. Check the saved/queued result and delivery status. Return to assistant when finished. | The assistant stays out of that chat while you handle it. A shop-wide pause stays on until resumed in Settings. |

For several products, use **Update prices & stock in bulk**. Enter only changed facts. Clearing an input means no change to that fact. Pending edits outside the current page are listed. Review, then Save changes. If part of a batch is saved and another row conflicts, **Reload remaining products** keeps saved rows, refreshes the unsaved edits and lets you review again. Download receipt if you need a record.

Use **Edit product** for names, photos, aliases, units, pack details or publication. Routine price and stock buttons avoid reopening all publication checks.

## Three things to remember

1. Orange values are suggestions. Check the item, unit and price against the actual shop. Unknown price/stock is not zero; a free item requires explicit confirmation.
2. A saved/queued WhatsApp reply is not proof of delivery. If the result is uncertain, use the same retry or check the conversation; do not start another identical operation.
3. Check your bank/UPI app before recording an advance. Send a refund through the bank first, then record its **separate actual refund reference**. Recording does not move money. Customer cancellation has an explicit confirmation and does not invent a completed refund.

## A brief teaching session

Demonstrate one quote, one pickup, one price/count change and one takeover. Explain the main action and the three rules above; show the ? button. Then let the trainee do these in a synthetic store without instructions:

- Resolve one missing price and send the correct quote; save a separate unfinished draft.
- Accept an approved order, mark it ready and record collection.
- Change one price without changing stock; count stock while preserving held items.
- Take over, send one reply and return the chat to the assistant.

Record completion, wrong turns, help requested, accidental changes and the trainee's words. Repeat only the task that required help. Accept the daily flow when all four tasks complete without coaching and there is no wrong product/unit/price, unintended count, duplicate send or false payment record. Record time; do not claim a time improvement without before/after measurements.

## தமிழ் விரைவுக் குறிப்பு

**இன்று** பக்கத்தில் தொடங்குங்கள். உதவி தேவைப்பட்டால் மேலே உள்ள **?** பொத்தானைத் தட்டுங்கள். மொழியை **தமிழ்** என மாற்றலாம்.

- **விலைப்பட்டியல்:** ஆர்டர்கள் → கவனிக்க வேண்டியவை → சரியான ஆர்டரைத் தேர்வு செய்யுங்கள். படம், பொருள், எண்ணிக்கை, விற்பனை அளவு, கடை விலையைச் சரிபாருங்கள். விவரங்களை நிரப்பு பொத்தான் அடுத்த விடுபட்ட / தவறான விவரத்துக்குச் செல்லும். முடிந்ததும் ஒப்புதலுக்கு அனுப்புங்கள். வரைவைச் சேமித்தால் வாடிக்கையாளருக்கு அனுப்பப்படாது.
- **பொருள் வழங்கல்:** வாடிக்கையாளர் ஒப்புதல் அளித்த பிறகு இருப்பையும் தேவையான முன்பணத்தையும் சரிபார்த்து ஆர்டரை ஏற்கவும். பொருட்களைப் பொதி செய்து எடுக்கத் தயார் எனக் குறியுங்கள். கொடுத்த பிறகே கொடுத்துவிட்டதாகப் பதிவு செய்யுங்கள். இது பணம் பெற்றதற்கான பதிவு அல்ல.
- **விலை / இருப்பு:** பொருட்கள் பக்கத்தில் விலையை மாற்று அல்லது இருப்பை மாற்று என்பதைத் தேர்வு செய்யுங்கள். இருப்பு தெரியாவிட்டால் முதலில் கடையில் எண்ணுங்கள். ஆர்டர்களுக்கு ஒதுக்கிய பொருட்களையும் சேர்த்து எண்ண வேண்டும். சேமிக்கும் முன் முடிவைப் பாருங்கள்.
- **பதில் அளித்தல்:** செய்திகள் → வாடிக்கையாளர் → நான் பதில் அளிக்கிறேன் → பதிலை அனுப்பு. முடிந்ததும் உதவியாளரிடம் ஒப்படையுங்கள். கடை முழுவதற்கும் நிறுத்தியிருந்தால் அமைப்புகளில் மீண்டும் தொடங்க வேண்டும்.

ஆரஞ்சு விலை ஒரு பரிந்துரை மட்டுமே. வங்கியில் பணம் வந்ததையோ திருப்பி அனுப்பியதையோ சரிபார்த்த பிறகே பதிவு செய்யுங்கள். அனுப்பக் காத்திருப்பது சென்றடைந்ததற்கான உறுதி அல்ல. பதிவு செய்தல் பணத்தை அனுப்பாது.

தமிழ் சொற்களை உண்மையான கடைப் பணியாளர்கள் சரிபார்த்து ஏற்க வேண்டும்; இந்தக் குறிப்பு அவர்களின் நடைமுறைப் பயிற்சிக்குப் பதிலாகாது.
