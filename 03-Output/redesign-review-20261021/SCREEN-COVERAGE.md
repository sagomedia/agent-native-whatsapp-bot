# PDF page coverage

21 October 2026. All 30 pages rendered. Contact sheets cover every page; principal order, stock, chat, settings, access and list views were also inspected enlarged. There are 27 screen concepts across both PDFs, plus two covers and one independent-review page. All page numbers below refer to actual PDF pages.

`Retain/refine` means the direction is useful but needs the listed behavior. `Restructure` means adjust the task rather than copy the screen literally. Gaps are unspecified states, not assertions that a working app is broken.

## Required additional states, rather than another full set of default screenshots

Prepare targeted interactive cases for: quote dirty/saving/saved/failed/conflicted; customer waiting/declined/expired/amended; quoted but undelivered/uncertain; acceptance/stock shortage/packing/ready/collection; receipt/refund review; stock-count conflict and partial bulk save; owner takeover/resume/global pause; auth expiry/offline/reconnect; empty/search/no-image states; soft keyboard and long Tamil labels.

One working component with these states is more useful than redrawing every default view before testing it.
