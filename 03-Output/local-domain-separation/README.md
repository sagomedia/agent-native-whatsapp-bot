## Daily use and recovery

Run `npm run local:db -- start`, then `npm run whatsapp:local` from the app folder. Wait for `LOCAL_ROUTE_READY`, use the **local** URL for the local product snapshot/chats, and send a fresh message from the configured test phone to the existing WhatsApp number. Sign in separately on the VPS URL to inspect VPS data. A distinct hostname does not duplicate WhatsApp delivery or share the two databases.

Ctrl+C restores the webhook to the VPS and disables the local host routes. The watchdog also restores after tunnel/backend loss, and the session expires after six hours. Recovery is `npm run whatsapp:restore`. DNS records may remain while offline; they reach the tunnel's 404 fallback, not the VPS application. Do not reinstall the old shared-domain helper or start a second connector to bypass this separation. Do not deploy while a local session is active.
