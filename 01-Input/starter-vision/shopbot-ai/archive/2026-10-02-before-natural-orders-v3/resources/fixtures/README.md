# Fixture scope

Begin with a small clearly synthetic hardware catalog sufficient for ambiguous variants, units, stock states, and cart requests. Add a second retail store/profile after the shared path works, to test isolation and reuse.

Mock structured text/image/audio outputs and provider usage let state/UI tests run without paid keys. Add owner proposal and payment-event fixtures when those slices ship.

Mocks do not prove native media extraction, model accuracy, language coverage or live delivery. Later 50-SKU evaluation uses real records and independent photos/voice notes.

Production cannot run demo seed/reset.
