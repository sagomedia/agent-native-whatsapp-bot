# Text, photo, and voice search

## Shared result contract

Search returns candidate SKU/family identifiers, matched evidence, missing specifications, and a reason to clarify or hand off. Prices and stock are fetched from catalog services after candidate selection, not generated by the model.

## Retrieval sequence

1. Resolve explicit product/SKU identifiers and structured specifications first.
2. Normalize the query against merchant-approved aliases and local names.
3. Retrieve a bounded candidate set using text/specification filters.
4. For a photo, inspect visible category, shape, branding, packaging text, and specifications through a vision adapter. Compare only relevant approved candidates. Stored image embeddings are an optional improvement after baseline evaluation.
5. Ask for a missing size/thread/material/model or a clearer label photo when that changes the SKU.
6. Show a few useful candidates and let the customer choose. Validate the exact variant before cart insertion.

Do not send all catalog images to the model. Do not search the public web during ordinary customer matching. If uncertainty persists, return a clear handoff rather than repeat expensive model calls indefinitely.

## Voice

Transcribe the voice note, preserve the customer's units and quantities, and feed the transcript into the same search flow. If a size, number, or product name is unclear, ask the customer to confirm it. Start with voice input and text replies; synthesized voice replies are unnecessary for this trial.

English/Tamil and mixed-language requests are proposed trial coverage pending merchant confirmation. Account for local nicknames and code-switching through reviewed aliases and real recordings.

## Model selection and limits

Choose the lowest-cost configuration that passes the actual trial tests. Keep vision, text, transcription, and optional embeddings replaceable. Set configurable attachment-size, audio-duration, retry, and per-conversation spend limits based on provider capabilities and trial measurements.

Do not accept a model's self-reported confidence as measured accuracy. Record whether the correct product was retrieved, whether clarification was appropriate, and whether an unsupported exact claim was made.

## Meaningful failures to test

Two near-identical sizes; unlabeled fasteners; obscure packaging; a brand/model outside the catalog; multiple objects in a photo; blurred text; a voice note with an ambiguous quantity; and a customer demanding an exact match when the evidence is insufficient.
