# Cost and operations

Meter the first real call. Target zero/one inference for routine actions; bound attempts/reasoning/output and account for every retry.

Direct SDK is a complexity choice, not a token discount. Measure whole conversations, useful outcomes, support and infrastructure before claiming affordability.

Start app + PostgreSQL with durable jobs in-process. Add deployment components only after measured contention or operational need. Retain protected credentials, database/media backups, health checks, permissions and recovery.

Usage reports precede billing automation. Preserve high-precision costs, separate merchant billable policy, gateway/payment accounts, and actual/estimated/unknown status.
